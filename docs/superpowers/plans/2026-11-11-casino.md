# Casino Rebuild Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Track steps below.

**Goal:** Rebuild Vaccoin as a large three-storey PSX casino with deterministic mixed valuables.

**Architecture:** A single layout module supplies floor surfaces, solid walls, rooms, furniture and machine positions to rendering, movement and rewards. Retain the fixed-step player and suction simulation, extending item rendering and score accounting.

**Tech Stack:** TypeScript, Three.js, Vite, Vitest, Playwright.

**Spec:** docs/superpowers/specs/2026-11-11-casino-design.md

## Global Constraints

- Preserve movement, vacuum interaction, 60-second clock, accounts and workshop data.
- Fixed reward placements and payouts; values 1, 10, 25, 100, 250, 500 initially.
- Preserve existing unrelated edits and source archives. No remote deployment/reset.
- User said to begin; execute inline without another process approval gate.

## Review Focus

- Stair openings must not have invisible floor/ceiling barriers.
- Coins must not collect through room walls or floor decks.
- Rare pickups must score once, reset completely, and stay within validation bounds.
- Geometry batching must preserve materials and avoid loading all source ZIPs.
- Existing account edits, workshop saves and leaderboard failure handling must survive.
